# Scope A offline analysis (batch B, 100 rows)
## T0 Inventory
- rawcounts: batchB/out{N}-rawcounts.json (N=0..99; 10 extra voutN = validation runs, ignored). Each holds pars (7 features), labels (all 8 incl usable_conns1), and rawcounts: per-post-neuron aggregate incoming AMPA-from-pyr onto interneurons / GABA-from-int onto pyramidals (nS), counts of zero-input cells, and `classes`: per (pre->post:conntype) census = connections, pairs, summed g_peak_sum_nS, num_receptors, max pair g.
- Mapping out{N} -> table row `sample`=N+1: verified by exact match of all 7 features AND all 8 label values for all 100 rows (ok=True).
- Labels (thresholds, nS of summed g_peak per pair): usable_pyr_int = #pairs pyr->int AMPA with g>=0.98; usable_int_pyr = #int->pyr GABA pairs g>=0.80; usable_int_int = #int->int GABA pairs g>=0.80; usable_conns2 = pyr->pyr per-pair criterion (27.44/CUESIZE per pair); frac_int_driven = fraction of interneurons whose summed incoming AMPA-from-pyr >=7.84; frac_pyr_inhibited = fraction of pyramidals with summed incoming GABA-from-int >=16.0; frac_pyr_inhibited_w05 = same with threshold 16*0.5=8.0. Unknown-type neurons inferred as interneurons.
- Added continuous targets raw_{pyr_int,int_pyr,int_int,pyr_pyr}_{n,g}: n = number of connections (== pairs) and g = total summed g_peak_sum_nS of class pyr->int:1, int->pyr:2, int->int:2, pyr->pyr (types 1+3 summed). Means: pyr_int n 31.4/g 34.3; int_pyr 78.8/72.6; int_int 12.9/11.3; pyr_pyr 4009/15311.
- Seeds: CONSTANT. All 100 runN/run.log (and the aborted one) contain randomseed=20240628 (101/101); the "seed54" in row_source is only the Sobol sampling seed. So netmorph growth noise is correlated across samples (same RNG seed), which means the label noise is not independent replication noise; no repeat-seed replicates exist so true noise floor can't be measured.
## Method notes / caveats
- statsmodels NOT installed -> no NB model (M1NB skipped); bootstrap-500 SEs for M1 coefficients. sklearn was not in the given venv; borrowed sklearn 1.9.1/joblib/threadpoolctl/narwhals from the BrainGenix-NES venv via symlinks in A/skl (pure import, worked with numpy 2.2.4).
- Poisson models = sklearn PoissonRegressor, standardised features, ridge alpha=0.01 (all of POIS7, M1, M2, in T1/T3/T4). M2 offset implemented by fitting y/exp(off) with sample_weight=exp(off) (equivalent Poisson likelihood). M1 coefficients reported back on raw feature scale.
- Continuous raw_*_g targets are fitted with the Poisson quasi-likelihood (non-integer y OK).
- frac_* modelled as count = frac*n_post, converted back and clipped to [0,1]; metrics on the fraction scale; M2 skipped for frac and M2 for usable_conns2/pyr_pyr uses n_pre*(n_pre-1).
- Folds: RepeatedKFold(5,10,random_state=0), identical for all models. RF7: 500 trees, min_samples_leaf=1, random_state=0. D2 = 1 - dev(model)/dev(train-mean base) per fold (predictions clipped at 1e-6); pooled D2 uses pooled OOF vs. fold-wise base OOF. Spearman of BASE is NaN (constant) -> shown nan. top-10 precision: ties broken by stable argsort.
- T3 used RF with 100 trees (not 500) for speed; subsets seeded by (1000*rep+n); y all-zero subsets skip the Poisson models (counted as "f<k>" next to rho). T3 subsets size n_train in {5,10,20,40,80} with test = remaining rows.
- T5: integer sampling of days 20-25, pyr 16-70, int 16-30, minsep 10-15, radius 100-200, thickness 20-50, dm.weight 0.1..1.0 step 0.1; density=(pyr+int)/(pi r^2 t *1e-9 mm^3).
- T6 is in-sample OLS (no CV). Variant B predicts at median V because V is not specified for the query configs.
