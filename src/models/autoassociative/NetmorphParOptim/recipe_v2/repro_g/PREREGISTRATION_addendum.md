# repro_g PREREGISTRATION addendum (written 2026-11-18 19:20 (RST1 was at 76%, nothing of it analysed), after the SEQ/CON stage was analysed and before the RST1/RST2/RST3 runs (started 19:06 on a freshly restarted NES, pid 2164826) were looked at in any way; not edited afterwards)
## What the SEQ/CON stage showed (so these are post-hoc observations, not tested predictions)
Preregistered scoring on arbor length means (P1-P6): all six runs are arbor class A to 9 digits (P1 hit, P3 no deviation, P5 yes (25%: the "all identical" branch), so the restart stage was run as the rules say). But the length means are blind to geometry. Comparing node positions (1,198,886 nodes in all six; node ids and soma positions identical, parent index identical for 99.9%): SEQ1, SEQ2, SEQ3 and the old linefix_b run agree with each other in only ~70% of node positions, CON1, CON2, CON3 (launched within 6 s of each other) agree with each other in 98.9-99.4% and with the SEQ runs in ~70%. The first differing node of every pair differs by 1e-6 um (the last printed digit), then the difference grows (1e-5, ... up to 60-125 um): floating-point-level nondeterminism amplified by chaotic growth, not a different random stream. Total lengths do not depend on direction, so most runs keep the same length means while geometry (and therefore synapse counts, 1-3%: Pyr->Pyr 5,793-5,959 over the six runs) differs.
## New hypotheses for the source of the ulp-level differences (ranked)
- **HA (45%): order-dependent floating-point summation whose order follows heap addresses** (std::set<neuron*> / std::set<fibre_segment*> iterated and summed in axon_direction_model.cc:660/682, or other pointer-ordered containers). Runs started on the same heap state and in the same allocation pattern get the same order. Predicts: RST1 (first growth after a fresh NES start, alone, exactly as SEQ1 was) agrees with SEQ1 in > 99% of node positions; RST2 and RST3 (concurrent, after RST1) agree with each other in > 95% (like CON1-3) and only ~70% with RST1 and SEQ runs.
- **HB (20%): launch-time dependence** (some quantity derived from time(NULL) or wall-clock at start). Predicts: RST1 agrees with SEQ1 in only ~70% (different start time), RST2/RST3 (started 3 s apart) agree with each other in > 95%.
- **HC (10%): a thread race or other run-to-run random FP perturbation.** Predicts: RST1 ~70% with SEQ1 and RST2 ~70% with RST3 (no mutual agreement); contradicts the CON1-3 mutual agreement, hence low.
- **HD (25%): other** (for example process-history dependent allocator behaviour not captured by HA).
## Rules
Agreement = fraction of nodes with |position difference| < 1e-3 um (pairmat.py). HA supported if RST1 vs SEQ1 > 0.99 and RST2 vs RST3 > 0.95; HB supported if RST1 vs SEQ1 < 0.9 and RST2 vs RST3 > 0.95; HC if both < 0.9; anything else HD. One restart, one fresh-process first run: weak evidence (a single clean outcome moves HA vs HB by about 2x); a stronger test would repeat the restart twice and vary the number of earlier runs, which is listed as follow-up, not run here.
