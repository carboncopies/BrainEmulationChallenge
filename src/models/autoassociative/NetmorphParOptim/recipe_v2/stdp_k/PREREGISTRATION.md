# stdp_k PREREGISTRATION (2026-11-19; written after the capability probe described below and before any experiment run; not edited afterwards)
Task STDP (John): does repeated recall / ripple-like activity strengthen the programmed memory pairs and weaken others, without runaway or breaking R3 recall, on the E4 recipe (V1 arbor, 20 interneurons, pyramidal D 0.0175, interneuron D 0.03, line-379-fixed build)? Patched instance only (NES 8011 / API 8010); main NES 3156209 / API 1972355 untouched; no git, no email, no NES code change; max 3 concurrent sims, numerical jobs at most 3 processes x 4 threads.
## 1. What the simulator supports (read from source and verified by a capability probe)
Source (BrainGenix-NES/Source/Core): `Simulation/SetSTDP(DoSTDP)` sets `Sim.STDP`; when true, every spike of a postsynaptic LIFC neuron (including forced `SetSpecificAPTimes` spikes) calls `LIFCReceptorData::STDP_Update(tfire)` (Structs/Neuron.cpp:162) for each of its incoming receptor groups. Rule: t_pre = last spike time of the presynaptic neuron (skip if it never fired); dt = tfire - t_pre - STDP_Shift; if dt >= 0: dw = A_pos * (dt/tau_pos) * exp(-dt/tau_pos), else dw = A_neg * (dt/tau_neg) * exp(dt/tau_neg) (negative); weight += dw, clamped to [0, 1]; conductance g = min(g_peak_sum, weight * g_peak_sum * kernel). Parameters are per receptor class and are set in NetmorphManagerThread.cpp (not settable through the API): AMPA = STDPHEBBIAN, A_pos 0.027, A_neg 0.02, tau_pos = tau_neg = 7 ms, Shift = -4 ms; NMDA and GABA = STDPNONE (no plasticity of NMDA or GABA).
Consequences read from the code: (i) with Shift = -4 ms the effective dt = (t_post - t_pre) + 4 ms is >= 0 whenever the presynaptic spike is not more than 4 ms after the post spike, and the update only runs at post-spike times with t_pre <= t_post, so the depression branch can practically never fire: the implemented rule is potentiation-only. (ii) A single post spike updates every incoming AMPA group whose presynaptic cell has EVER fired (kernel peak at t_post - t_pre = 3 ms, 0.37 x A_pos = 0.0099 per pairing; 1.5e-3 at 20 ms; ~3e-6 at 100 ms). (iii) It also updates pairs with weight 0 (pruned by the R3 programming at c = 0); no new connections can appear (the grown connectome fixes the pairs and g_peak_sum).
Capability probe (before this preregistration; files probe_stdp.py, probe_on.json, probe_off.json; model s33333; 9 distinct strong Pyr->Pyr pairs, 20 forced pairings each, 100 ms apart): STDP on: pre-before-post by +1/+3/+6/+10/+20/+50 ms changed weight 0.2 -> 0.389/0.399/0.385/0.544/0.260/0.202 (+0.0094/+0.0099/+0.0092 per pairing at +1/+3/+6; the +10 pair also had extra network spikes), post-before-pre by -3/-8/-20 ms changed nothing (0.200 -> 0.200), NMDA (type 3) and GABA (type 2) weights unchanged in all 2,405 / 1,174 connections, 211 of 3,299 AMPA connections changed in total; STDP off: 0 of 3,299 changed. So STDP IS supported, only on AMPA, only potentiation. The simulator runs STDP; no offline substitute is needed for the main experiment. Because the simulator rule has no depression, "weaken others" cannot be tested with it; I therefore add a clearly labelled OFFLINE analysis (section 5) applying standard literature rules with depression to the measured spike trains.
## 2. Hard caps (bio_ranges.json)
bio_ranges.json contains no synaptic-weight entry (only growth parameters, D_synmax 0-1.5 / 0-0.15 limits, dm.weight 0.1-1.0 as a growth parameter). Caps used and checked on every sim: all AMPA weights stay in [0, 1] (simulator clamp, verified on readback) and every conductance <= the grown g_peak_sum (so no connection is stronger than the grown, D_synmax-limited connectome allows); the STDP parameters are the simulator's fixed defaults and are not changed; no growth or bio_ranges parameter is modified. A run in which any weight lies outside [0, 1] or any conductance exceeds the grown g by more than 1e-6 nS is reported as a violation (and counts as FAIL for the cap rule).
## 3. Experiment (simulated, STDP on only during training)
Models: all 10 grown E4 models (s16180, s27182, s31415, s11111, s22222, s33333, s44444, s55555, s66666, s77777), reused, no regrowth. Design: the disjoint 4+2 packing of each model (the "R42" designs of ripple_overlap_j, 2-4 memories, 28 memories in total; 8-cell memories not used), programmed as R3 (cue->non-cue 4.125 nS per pair etc., headline_i / ripple_overlap_j programming, unit-checked), background c = 0 and 0.15 nS, GABA on (as grown; silenced GABA not run).
Training arms (STDP on): A1 = full-cue recall: R repetitions of cueing each memory with its 4 cue cells (offsets 0 / 0.5 / 1.0 / 1.5 ms), memories interleaved, 500 ms between events; A2 = ripple-like partial cue: R repetitions of the 3-cell partial cue (cue[1:]) plus a second spike in each of the 3 cells 1000/f ms later, f cycling 100, 150, 200, 250 Hz with the repetition index (the n = 2 event of ripple_overlap_j, which replays the memory). Doses R = 10 and R = 100 per memory. Controls: R = 0 (programmed weights, no training) through the identical probe path. All drive inside the ranges stated in ripple_overlap_j/PREREGISTRATION.md (forced spikes <= 250 Hz, <= 2 spikes per cell and event).
Readout 1 (weights): all AMPA weights (Pyr->Pyr and Pyr->Int; 3,3xx connections per model) read back after training and compared with the programmed values, by class: (a) cue->non-cue memory pairs, (b) non-cue<->non-cue loops, (c) non-cue->cue loops, (d) cue->cue, (e) Pyr->Int AMPA from cue cells, (f) pairs between members of different memories, (g) pairs involving a cell that is in no memory, (h) all other AMPA pairs. Also: number of weights that decreased; fraction of cue->non-cue pairs at the cap (weight 1).
Readout 2 (stability, from the training spikes): non-member Pyr spikes per recall event; runaway = > 50 spurious non-member Pyr spikes in an event; interneuron spikes per event.
Readout 3 (R3 recall after training): the trained weights are programmed into a FRESH simulation of the same model (STDP off) and each memory is probed with the full cue, 3-cell cue a and 3-cell cue b (500 ms apart), as in ripple_overlap_j mode ov. Metrics: full cue completes (all non-cue within 10 ms), 3-cell cues silent (selectivity), no non-member Pyr spike, no other memory's cell firing.
Sim count: 10 models x 2 arms x 2 doses x 2 backgrounds = 80 training sims + 80 probe sims + 20 control probe sims = 180 sims (a training sim and its probe sim run in one process, one after the other).
Offline input to the predictions (computed before running, from the grown conductances only): cue->non-cue grown conductances G (28 memories x 8 pairs) have quantiles min 4.9, 25% 4.9, median 5.88, 75% 7.84, 90% 9.8 nS; R3 weights are 4.125/G (0.20-0.84). If every cue->non-cue weight were at the cap (w = 1), the cap-level conductance sum from a 3-cell cue (min over the memory's non-cue cells) is >= 16.5 nS for at least one of the two 3-cell cues in 24 of 28 memories (86%); the observed firing threshold of a cell lies between 12.4 nS (silent) and 16.2 nS (fired, ripple_overlap_j mechanism case).
## 4. Predictions (falsifiable) for the simulated experiment
- S1 (potentiation only): no AMPA weight decreases anywhere (0 decreases among all connections of all 80 training sims): 99%.
- S2 (memory pairs strengthen): per full-cue recall (arm A1) the cue->non-cue weight rises by 0.009-0.022 per recall (peak kernel 0.0099 per post spike, a non-cue cell fires 1-2 times); after R = 10 the mean cue->non-cue weight change is +0.09 to +0.22 (pairs with W0 + 0.1 > 1 clipped), after R = 100 at least 90% of cue->non-cue pairs are at the cap w = 1 (conductance = G): 85%.
- S3 (loops): non-cue<->non-cue loops (post spikes 0-1 ms after pre, dt ~ 4-5 ms effective) rise by about 0.008-0.015 per recall, cue->cue (offset 0.5-1.5 ms) by 0.007-0.010 per recall; non-cue->cue loops (post cue fires 4 ms BEFORE the non-cue pre) change by < 0.001 per recall (no depression; last pre spike is 500 ms old): 80%.
- S4 (others unchanged): AMPA pairs involving a cell that never fires (class g) and pairs between members of different memories (class f) change by exactly 0 or < 0.001 after R = 100 at c <= 0.15: 90%; so relative to the memory pairs "others" are not weakened (they simply stay): in the simulator "weaken others" is FALSE by construction.
- S5 (arm A2): the 3 forced cue cells' pairs to the non-cue cells strengthen like A1 (within a factor 1.5 per recall); the 4th (unforced) cue cell's pairs change by < 0.001 (it does not fire): 80%.
- S6 (stability during training): no training event with > 50 non-member Pyr spikes (runaway) at R = 10 in any model at c <= 0.15 (95%); at R = 100 in at least 9 of 10 models (85%) and in none at c = 0 (80%).
- S7 (R3 recall after R = 10): full cue completes and 3-cell cues stay silent in >= 90% of memories (80%); no non-member Pyr spikes (85%).
- S8 (R3 recall after R = 100): full cue completes in >= 95% of memories (90%), but selectivity is lost: at least one 3-cell cue completes (>= 1 non-cue member fires) in >= 40% of memories (70%); in A2 (partial-cue training) in >= 50% of memories (65%). Non-member Pyr spikes in the probe at c = 0.15: in <= 20% of memories (70%).
- S9 (controls): R = 0 probe through the new path reproduces the earlier result (full cue completes, 3-cell silent, no non-member spikes) in 100% of memories at c <= 0.15: 97%.
## 5. Offline literature-rule analysis (secondary, NOT simulated; labelled as such everywhere)
Purpose: test "strengthens memory pairs and weakens others" with a rule that has depression. Input: the recorded spike trains of the A1 / A2 training sims (these spikes were produced by the simulator with its own STDP on; they differ from STDP-off trains only after weights saturate). Rules (all-to-all pair-based, additive, weights bounded to [0, 1] in weight units, applied to every AMPA pair whose two cells both spike): (L1) Song, Miller & Abbott 2000 (Nat Neurosci 3:919): A+ = 0.005, A- = 1.05 x A+ = 0.00525, tau+ = tau- = 20 ms, bounds 0 and g_max; (L2) Bi & Poo 1998 (J Neurosci 18:10464) time constants as used by van Rossum et al. 2000: tau+ = 16.8 ms, tau- = 33.7 ms (recalled from memory, not re-verified here), same A+, A-. Both are inside the biological range of hippocampal pair STDP (windows of ~20-40 ms, per-pairing steps of 0.5-1% of the weight scale in Song et al.); weights capped to [0, 1] of the grown conductance. Predictions L: per recall, cue->non-cue +0.004 (L1: 0.005 x exp(-3.75/20) = 0.0041; range 0.003-0.006), non-cue->cue loops -0.004 (post cue cells fire 3-4.5 ms before the non-cue pre: -0.00525 x exp(-3.75/20) = -0.0044; range -0.003 to -0.006), cue->cue near 0 (|dw| < 0.002), pairs involving non-members exactly 0, other-member pairs ~0; after R = 100 the non-cue->cue loops are clipped at 0 (>= 80% of them at weight 0) and cue->non-cue pairs raised by about 0.4 (to the cap for G <= 7 nS): 70%.
## 6. Verdict rules (fixed now)
- Q1 "strengthens memory pairs" (simulated): PASS if after R = 10 (A1, c = 0.15) the mean cue->non-cue weight rises by > 0.05 in >= 8 of 10 models and no weight of class (a) decreases.
- Q2 "weakens others" (simulated): PASS only if >= 5% of AMPA pairs of classes (c),(f),(g),(h) show a decrease; predicted FAIL (no depression in the simulator). The offline literature rule (section 5) is judged separately: PASS if non-cue->cue loops decrease by > 0.02 after R = 10 while cue->non-cue pairs increase.
- Q3 "no runaway": PASS if S6 holds (no event > 50 non-member Pyr spikes) in >= 9 of 10 models for all arms/doses at c <= 0.15.
- Q4 "R3 recall preserved": PASS if after training (all arms and doses at c <= 0.15) in >= 90% of memories full cue completes, 3-cell cues are silent and no non-member Pyr spikes occur; PARTIAL if full-cue recall is intact (>= 90%) but selectivity (3-cell silence) or no-spurious-spikes fails; FAIL if full-cue recall breaks (< 90% complete) or runaway (Q3 fails). Predicted: R = 10 PASS, R = 100 PARTIAL.
- Cap rule: PASS if no weight outside [0, 1] and no conductance above the grown g in any model.
Scoring of predictions: HIT inside the stated range, PARTIAL within 25% beyond, MISS otherwise; counts reported per model/memory/trial.
## 7. Limits stated in advance
Simulator STDP = potentiation-only, nearest-last-pre update at post spikes, parameters fixed by the code (cannot be set through the API; no code change allowed); forced spikes drive the recall; one deterministic run per cell (Seed 0); 28 memories in 10 models; R3 programming imposed; STDP not applied during probes; GABA silenced not run; training with STDP on affects the whole network (every pair whose cells fire). The offline literature analysis uses the simulator-produced spike trains and does not feed back into the network.
