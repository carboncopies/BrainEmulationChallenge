## #1 design (strongest-pair pruning, "D1")
- Models (5 seeds): 33333, 44444 (existing B1 growths in randal_reply_n/grow_B1_s*, reused), 55555, 66666, 77777 (NEW B1 growths: Pyr D 0.035, Int D 0.03, same recipe/driver logic as randal_reply_n/grow_arm.py arm B1, model names v2-fr-B1_s*). Same-seed baselines = headline_i E4 growths (D 0.0175).
- Pruning rule (fixed now): on the Pyr->Pyr pairs of the B1 dump, sort by number of synapses (num_receptors) descending, ties broken by a seeded random key (np.random.RandomState(20261123 + seed)); keep the first floor(0.29 x 9120) = 2644 pairs, set every other Pyr->Pyr pair to weight 0 (removed from the effective graph; kept pairs keep their grown conductance, no rescaling). Pyr->Int and all interneuron pairs unchanged. Controls (offline only): (a) unpruned B1, (b) random-pair pruning to the same p (seeded), (c) baseline.
- Bars 1-7 on the pruned effective graph = same definitions as randal_reply_n/bars.py (p in 0.1-0.3; Pyr->Pyr synapses/connected pair 1.9-4.5; Int->Pyr/pair 4-9; Pyr->Int/pair 1.5-4.5; drivable interneurons >= 7 of 20 (8-cell criterion); bio_check hard limits pass; inhibitory fraction A = Int->Pyr/(Int->Pyr+Pyr->Pyr) 25-50%). Bars 3, 5, 6 depend only on the B1 growth itself (not on pruning), bars 1, 2, 4, 7 are recomputed on the pruned graph. Soft flag (mine, not a hard limit): share of connected Pyr->Pyr pairs with >= 5 synapses <= 20%; also reported: fraction of grown pairs set to weight 0, strong pairs (>= 4.125 nS), in-degree CV.
- Capacity count K42 = max number of disjoint memories of 4 cue + 2 non-cue cells found by feas2.py (cue sets with >= 2 common strong targets, strong pair >= 4.125 nS, 300 random-restart greedy packings; sampled lower bound when > 3e6 subsets, as in the earlier work) on the effective Pyr->Pyr matrix, reported next to the same-seed baseline value from headline_i/feas_V1n20_s*.json (33333: 3, 44444: 2, 55555: 2, 66666: 3, 77777: 4) with the SAME script. Also K44 (4+4) and, with ovlib.pack, the max number of 4+2 memories with pairwise overlap <= 1 (K42o1).
- SUCCESS of #1 (from FRESH.md, fixed now): a model is a success if (i) K42 >= 3 x its same-seed baseline value AND (ii) all 7 bars pass on its pruned graph AND (iii) recall of its programmed memories (below) is clean. #1 succeeds overall if >= 3 of the 5 models are successes. A weaker report-only line: models with K42 >= 2 x baseline. If K42 < 2 x baseline on most models the idea is reported as failed.
- Recall protocol (patched API only): load the REAL B1 model (v2-rrn-B1_s33333/s44444, v2-fr-B1_s55555/66666/77777), program through the API in this order: AMPA by legacy BatchSetPrePostStrength (R3 recipe pair conductances computed on the pruned effective graph, pruned pairs -> 0, pairs not in the recipe 0 for c = 0 or min(g, c) for background c), then NMDA = 0.56 x AMPA of the same pair (Neurotransmitter='NMDA'), then GABA = grown 0.2 weight (x1, Neurotransmitter='GABA'); STDP off; forced cue spikes 4 cells x 0.5 ms spacing; same as nmda_gaba_exp part A/B logic. Designs: D42 (feas2 groups, disjoint) and O1 (ovlib.pack, overlap <= 1, all memories programmed simultaneously). Conditions: background c = 0.15 and 1.5 nS. Events per memory: full 4-cell cue (expect complete: all non-cue members fire within 10 ms), each 3-cell sub-cue (expect silent: no non-cue member fires), 800 ms spacing. clean = completes when expected, silent when expected, no spikes of non-member pyramidal cells, no cell of another memory outside the cued one (full cross-completion = every exclusive non-cue member of ANOTHER memory fires). Baseline recall comparison on the same seeds with the same protocol on the unmodified E4 models (reuse nmda_gaba_exp part A raw files where seed/c/r/f match: seeds 33333, 66666, 77777 at c 0.15/1.5, r 0.56, f 1; run the missing seeds 44444 and 55555 myself).
- Capacity vs baseline reported as: K42, K42o1 (offline) and number of memories whose full cue completes cleanly in the sims, per model.

## #3 design (growth-programmed assemblies, "D4")
- Two growths, seeds 33333 and 44444, arm C1: Pyr D 0.0175 and Int D 0.03 as baseline E4, 8 groups of 6 pyramidal cells (group g = pyramidal indices 6g ... 6g+5, g = 0..7, i.e. the first 48 pyramidal cells; the other 48 are ungrouped). Per-cell steering lines in the style of randal_reply_n A4/A5 (the two region lines `In.attractedto=NGF_A; In.attractors=NGF_A;` replaced by per-cell lines for ALL cells): grouped pyramidal k of group g: attractors NGF_A NGF_G{g}, attractedto NGF_G{g} (own group's dendrites only); ungrouped pyramidal: attractors NGF_A, attractedto NGF_A; interneurons: attractors NGF_A, attractedto NGF_A (as E4). Interneuron axon dm.weight stays the global 0.9 (no own set; dm.weight = 0.9 for pyramidal axons). All bio_check hard limits pass. NOTE (stated in advance): any added parameter line reshuffles the axon random stream, so C1 differs from its baseline by lever + fresh realisation; n = 2 is descriptive only.
- Measured: own-group share = (Pyr->Pyr synapses from grouped cells onto the 5 partners of their own group)/(all Pyr->Pyr synapses of grouped cells), chance 5/95 = 5.3%; synapses per within-group directed pair; fraction of within-group directed pairs with >= 5 synapses; strong pairs (>= 4.125 nS) among group members; number of the 8 designed groups usable as 4+2 memories (any 4 of the 6 as cue, remaining 2 as targets, every cue -> target pair >= 4.125 nS; counted as the best split per group); bars 1-7; K42 by feas2 on the whole C1 graph vs baseline.
- SUCCESS of #3 (fixed now): within-group directed pairs >= 5 synapses for >= 50% of group pairs, AND bars 1-7 pass, AND own-group share >= 0.35. FAILURE: own-group share < 0.35 or any of those bars fails. Recall (only if at least 1 designed group is usable): programmed with the same protocol as #1 (grown conductances for the group's pairs per R3 recipe), c 0.15 and 1.5, designed groups plus any extra feas2 groups.
