**Definitions:**
- **RECOVER (per run):** 50% completion >= (LH reference at the same model and r) - 1.
- **TERM (per run):** every completing event stops100.
- **PASS_T:** as in PREREGISTRATION.md.

**Best neuron arm for B2 (rule fixed now):** compare RS2 and RS3 by these criteria, in order:
1. the number of models with TERM
2. the total number of 50% completions over the two models
3. the total number of events with non-member spikes (fewer is better)
4. if still tied, RS2 (closer to the anchored literature values)

The arm is chosen by neuron parameters only. B2 runs it at r 1.0 regardless of the r used in B1.

**Predictions (confidence):**
- **B1a:** residual sAHP at the cue onset of 50% events is <= 0.5 nS (median) in all 4 runs (85%).
- **B1b:** RECOVER in >= 3 of 4 runs (60%).
- **B1c:** where 50% completion recovers, events also last longer. The median *last* at 9 s is longer than at 3 s in >= 3 of 4 runs (60%). This follows the knob-scout model: 50% completion and ignition share one threshold, so there is no window.
- **B1d:** TERM in >= 1 run (35%); TERM on s77777 RS2 r0.56 again (55%).
- **B1e:** PASS_T in any B1 run (15%).
- **B1f:** 25%-cue, single-cell and unrelated cues recruit 0 in all runs (85%).

## B2: eigenvalue design (6 sims), r 1.0, GABA x1, 9 s spacing
**Member matrix.**
- Start from the LH matrix X_LH: learned pairs at min(G, 6.86), then per-cell scaling to 3T; rebuilt by `run_pl.arm_matrix(net, A, 'LH')`.
- For member pairs only (pre and post in A17, grown pair present), set X = fl + k·(X_LH - fl). Here fl = the 0.1·G weight floor, as used by LH's own cap scaling.
- Solve k by bisection so that rho(X[A, A]) = target. rho is the largest absolute eigenvalue of the 17x17 member AMPA conductance matrix in nS, the same definition as knob-scout, which I reproduced: LH 21.48 / 22.92, W70 16.98 / 17.88.
- Every other pair is as in LH.

**Computed before running** (weights as fraction of G, input in nS):

| model | target rho | k | member weights min / mean / max | max member input |
|---|---|---|---|---|
| s77777 | 16.0 | 0.692 | 0.10 / 0.515 / 0.723 | 57.2 (hub cell 3, as LH) |
| s77777 | 16.5 | 0.720 | 0.10 / 0.532 / 0.748 | 57.2 |
| s66666 | 16.0 | 0.646 | 0.118 / 0.517 / 0.682 | 47.6 |
| s66666 | 16.5 | 0.672 | 0.118 / 0.533 / 0.705 | 47.7 |

**Runs:**

|---|---|---|---|

| 7, 8 | E16 | best arm from B1 | s77777, s66666 |

**References** (stored, 3 s spacing, N0, r1):
- W70: rho 16.98 / 17.88. s77777: 75% 5/6, no runaway. s66666: 5/6, runaway 5/5.
- LH: rho 21.5 / 22.9.

**Predictions** (from the knob-scout thresholds: 75% completion at rho about 14.4-17.2, mean 15.8; ignition at 17.4 ± 1; no 50% window):
- **B2a:** E16 N0: 75% completion >= 4/6 in both models (60%), and TERM in both models (55%).
- **B2b:** E16 N0: 50% completion <= 1/6 in both models (75%).
- **B2c:** E16.5 N0: 75% completion >= E16's in each model (80%); TERM in >= 1 model (55%).
- **B2d:** the best neuron arm added to E16: 75% completion <= N0's in both models (70%); median *last* <= N0's in both (75%).
- **B2e:** a "75%-design pass" in >= 1 of the 6 runs (50%). This is PASS_T without the 50% clause: 75% >= 5/6, 25%/single/unrelated recruit 0, TERM, no non-member spikes.
- **B2f:** PASS_T, including 50% >= 4/6, in any B2 run (10%).
- **B2g:** s66666 and s77777 agree (both pass or both fail the 75%-design pass) at E16 N0 (55%). The point of the per-model eigenvalue is to remove the model difference that W70 showed.
