## EXPERIMENT 1: OVERLAP
Memory = 4 cue cells + m non-cue cells, m = 2 ("6-cell") or 4 ("8-cell"); every cue->noncue pair >= 4.125 nS (R3 feasibility, exact candidate lists as in feas2.py). Two memories overlap in k shared cells. Constraint (so that programmed pair values never conflict): a shared cell has the SAME role (cue or non-cue) in the memories that share it. Hence overlap types are cue-sharing (C) and non-cue-sharing (N), and mixtures in larger families.
Programming (new, `ovlib.py`, equal to dyn2.pair_list for disjoint memories, unit-checked): per memory R3 values; shared pairs get the same value (cue->noncue 4.125 nS exactly), non-cue->non-cue and non-cue->cue loops are rescaled per post cell over the UNION of pre cells with the same 8 nS caps, cue->interneuron summed cap 10 nS per memory (min over memories), everything else min(g, c).
Offline capacity (no sim): for each model and size, maximum number of memories in a packing with pairwise overlap <= k for k = 0, 1, 2, 3 (role-consistent, candidate lists exact, 300 random-restart greedy packings; the k = 0 number must reproduce the earlier disjoint counts), plus the number of overlapping pairs at each exact k and type.
Dynamic design: per model and size, design F_k (k = 1, 2, 3) = the maximal packing found for pairwise overlap <= k (6-cell memories), and F8 = the maximal packing of 8-cell memories with overlap <= 3, if >= 2 memories fit. Designs only run if they contain at least one pair with the stated overlap (for F_k at least one pair at exactly k). Each design is ONE sim holding all its memories simultaneously. Events per memory (500 ms apart, protocol of dyn2 single mode): full 4-cell cue (expect completion), 3-cell cue a, 3-cell cue b (expect silence). Conditions: c = 0, 0.15, 1.5 nS (uniform background per Pyr->Pyr pair) x GABA on / silenced. (c = 3.0 not run: runaway there is known and not the question.) Seed 0 (deterministic), single run per cell of the grid.
Per event: completion = all non-cue members of the cued memory fire within 10 ms of the cue onset window (as before); cross-completion (partial) = number of cells that belong to another memory but NOT to the cued memory and fire within 450 ms; full cross-completion = all non-cue exclusive members of some other memory fire; non-member Pyr spikes (cells in no memory); interneuron spikes. A trial is "clean" = (full cue: completion and no cross-completion, no non-member Pyr spike; 3-cell cues: no non-cue member of the cued memory fires, no cross-completion, no non-member spike).
### Overlap predictions (falsifiable)
- O1 (capacity, offline, per model; disjoint k = 0 must match earlier counts: 6-cell 2-4, 8-cell 0-1): max 6-cell memories with overlap <= k: k = 1: 3-6 (median 4); k = 2: 4-9 (median 6); k = 3: 5-14 (median 8). Strictly more at k = 3 than at k = 0 in >= 8 of 10 models (90%). Non-decreasing in k in 10 of 10 (certain by construction). 8-cell with overlap <= 3: 0-2 per model; at least 2 memories in 3-5 of 10 models; at most 3 memories in any model. Limit that I expect to bind: cells with >= 4 strong inputs are only 6-12 per model, so non-cue cells must be re-used (N-type sharing) for capacity to grow.
- O2 (recall, at c <= 1.5, GABA on): clean full-cue completion in >= 97% of memory trials (range 90-100%) for k = 1, 2, 3 each; 3-cell cues silent in >= 98%; full cross-completion in 0 trials (80%); partial cross-completion (any cell) in <= 2% of full-cue trials (70%); non-member Pyr spikes 0 at c <= 0.15 (85%).
- O3 (GABA): results at c <= 1.5 identical (same clean/not-clean per trial) with GABA silenced in >= 90% of trials (85%): inhibition is not what separates overlapping memories here, selectivity is the 16.5 nS threshold. 
- O4 (k dependence): C-type overlap (shared cue cells) with k = 3 is the hardest: the cue of A then gives B a 3-cell cue, so B's non-cue cells see 12.4 nS of 16.5; prediction: still silent (80%); the first failures if any appear in k = 3, c = 1.5.
- O5 (design-level): share of designs (model x F_k x condition) with ALL trials clean: k = 1: 85%, k = 2: 80%, k = 3: 70% (c <= 1.5 on).
### Overlap verdict rule (fixed now)
Per k: PASS if >= 95% of memory trials clean at c <= 1.5 with GABA on and no full cross-completion; PARTIAL 80-95%; FAIL < 80%. Reported separately for 6-cell k = 1, 2, 3 and 8-cell. Capacity claim "overlapping memories fit" is judged per model from the offline counts only.
## EXPERIMENT 2: RIPPLE-LIKE EVENT after a partial cue
Definition (closest event this simulator supports): a partial cue (3 of the 4 cue cells of a memory, offsets 0 / 0.5 / 1.0 ms as in the standard cue, the partial cue is cue[1:] of the sorted cue list, i.e. the first listed cue cell is dropped, exactly the dyn2 3-cell cue "b"; no selection of cells) is followed by a synchronous burst: each of the 3 cue cells fires n spikes in total at period 1000/f ms (f = 100, 150, 200, 250 Hz; n = 1 (plain partial cue = control), 2, 3). Duration of forced drive <= 20 ms; at most 3 spikes per cell; maximum instantaneous rate 250 Hz = top of the CA3 ripple band. Interneurons are NOT forced: "interneuron-paced" cannot be imposed; whether interneurons participate, how, and whether they lock to the pyramidal volleys are measured. No sharp-wave envelope, no other drive.
Designs: the disjoint packings (4+2 packing D42 and 4+4 packing D44 where it exists) of all 10 models, i.e. the earlier recall designs; conditions c = 0, 0.15, 1.5 x GABA on / silenced; events per memory: control, then n = 2, 3 x 4 frequencies (9 events), 600 ms apart, same sim. Deterministic seed, one run per cell.
Measures per event (window = 100 ms from the first cue spike; Pyr member volley = group of member spikes separated by >= 2 ms gaps): replay = all non-cue members fire; fraction of non-cue members fired; latency; number of member volleys and event frequency = 1000 / mean inter-volley interval of NON-CUE member volleys (needs >= 3); duration = first to last Pyr member spike in the window; interneuron participation = number of interneurons that spike / 20, spikes per participating interneuron, and the share of interneuron spikes occurring 1-6 ms after a member volley (locking); false completion = other-memory exclusive members fired, non-member Pyr spikes (> 50 = runaway).
### Ripple predictions
- R1 (control): n = 1 never completes any memory, c <= 1.5, on and SG: 97% (known from dynamics_c: 3-cell silent).
- R2 (replay): n = 3 at f = 150, 200, 250: replay (all non-cue members) in >= 80% of (memory x f) cases at c <= 0.15, GABA on: 60%. Temporal summation of 12.4 nS volleys 4-7 ms apart is predicted to complete the memory; at 100 Hz (10 ms) summation is predicted weaker: replay at 100 Hz lower than at 250 Hz in >= 6 of 10 models: 75%. n = 2 replays no more often than n = 3: 90%.
- R3 (false completion): no non-member Pyr spike and no cross-completion at c <= 0.15: 85%; at c = 1.5 non-member spikes (>50) in <= 5% of events: 80%.
- R4 (frequency): the non-cue response frequency follows the drive: within +-20% of f in >= 70% of replaying events with >= 3 volleys; but replaying events have only 2-3 volleys, so "event frequency" is undefined (<3 volleys) in >= 50% of replaying events: 70%.
- R5 (duration): event duration (first to last Pyr member spike) < 30 ms in >= 80% of replaying events (85%): this does NOT reproduce the 50-100 ms SWR duration.
- R6 (interneurons): participation in replaying events: median 20-40% (4-8 of 20) interneurons spike, 1-3 spikes each; >= 70% of interneuron spikes occur 1-6 ms after a member volley (feed-forward locking to pyramidal volleys, not inhibitory-loop pacing): 70%. GABA silenced changes the event frequency and duration by < 10% in >= 80% of paired events (the 10 ms GABA decay cannot pace 150-250 Hz): 75%.
- R7 (c effect): c = 1.5 does not change replay fraction by more than 10 points vs c = 0: 75%.
### Ripple verdict rules (fixed now)
(a) "partial-cue replay by ripple-frequency burst" = PASS if control silent (R1) and n = 3 at some f in the band replays >= 80% of memories at c <= 0.15 on, with no false completion (R3); FAIL if replay occurs in < 50% of memories at every f; PARTIAL otherwise.
(b) "ripple-like event" (judged separately): PASS only if, in replaying events, event frequency in 100-250 Hz with >= 3 volleys in >= 50% of events AND duration >= 30 ms in >= 50% AND interneuron participation >= 25%; predicted FAIL (80%) because the events are short and the frequency is imposed by the input, not generated by the network.
