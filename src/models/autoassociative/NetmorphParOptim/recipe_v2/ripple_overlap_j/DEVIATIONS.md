# Deviations from PREREGISTRATION.md (written 2026-11-19 07:11, after the offline packing counts, before any simulation; the preregistration itself is unedited)
1. Offline packing counts came out far above my predicted ranges (6-cell, overlap <= 3: 16-201 memories per model; I predicted 5-14). Simulating events for every memory of designs with up to 201 memories is too costly, so in designs with more than 24 memories ALL memories are programmed (the full overlapping structure is on) but only a fixed random sample of 24 memories (random.Random seeded; the chosen indices are stored in the design file) is cued (field "cued" in design_*.json). Prediction O2/O5 rates are scored on the cued memories. Designs F_k are only run if the packing contains at least one pair with exactly k shared cells (as preregistered).
2. My random-restart packing (150 restarts) at k = 0 gave 2-3 memories where feas2.py found 2-4 earlier (3 models lower); the k = 0 counts reported use max(mine, earlier feas2). k >= 1 counts are my packing's (lower bounds).
3. Ripple designs use the earlier disjoint packings (feas2 groups: 4+2 = "R42", 4+4 = "R44" where it exists), as preregistered ("D42 and D44").
4. Machine load: capacity runs were restarted throttled (3 processes, 4 BLAS threads each) at 06:58 at John's request; results unaffected (deterministic seed).
